# The Starred Bill

Compare lunch and dinner prices at London's Michelin-starred restaurants.

## Files

- `index.html`: the website (layout, styles and behaviour)
- `restaurants.js`: the restaurant list. Edit this file to change prices or add restaurants.

## Editing on GitHub

1. Open `restaurants.js` in this repository and click the pencil icon.
2. Change a price, or copy a line to add a restaurant (give it a new `id`).
3. Click **Commit changes**. The live site updates within a minute or two.

## Viewing locally

Double-click `index.html` to open it in your browser.
