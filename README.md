# The Starred Bill

Compare dinner and wine pairing prices at Michelin-starred restaurants in London and Taiwan, in English or Traditional Chinese.

- London: https://sbarnard310.github.io/starred-bill/
- Taiwan: https://sbarnard310.github.io/starred-bill/?city=taiwan
- Add `&lang=zh` for Chinese or `&lang=en` for English.

## Files

- `index.html`: the website (layout, styles, behaviour and all English/Chinese wording)
- `restaurants.js`: London restaurants, prices in £
- `taiwan.js`: Taiwan restaurants, prices in NT$ (shown in £ with today's exchange rate when chosen)

## Editing on GitHub

1. Open `restaurants.js` (London) or `taiwan.js` (Taiwan) and click the pencil icon.
2. Change a price, or copy a line to add a restaurant (give it a new `id`).
3. Click **Commit changes**. The live site updates within a minute or two.

## Viewing locally

The site loads its data files, so open it through a local web server rather than by double-clicking `index.html`.
